class icspacket.proto.iso_ses.session.ISO_Session(transport: COTP_Connection, settings: ISO_SessionSettings | None = None)[source]#

Implements the Connection-oriented Session Protocol (COSP) (ITU X.225 / ISO 8327-1) endpoint on top of COTP.

Provides session connection establishment, data transfer, and orderly release services using SPDUs (Session Protocol Data Units). This class ensures proper sequencing and validation of SPDUs according to ISO Session protocol semantics.

Parameters:

  • transport (COTP_Connection) – Underlying COTP transport connection.

  • settings (ISO_SessionSettings | None) – Session negotiation settings.

settings: ISO_SessionSettings#

Currently applied session settings
